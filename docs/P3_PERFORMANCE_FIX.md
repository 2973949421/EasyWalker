## 2. 实现内容

### 输入与 View

- 官方键盘公开接口每轮最多推进 8 次、约 2 ms；项目固定 16 项事件队列保留已捕获的短按。按住只派发一次，组合键、唤醒整组按键和过期页面事件继续被抑制。
- 25 ms 按住判定仍在；已捕获的按下/松开不会因为短于该窗口被直接丢弃。软件无法恢复硬件 FIFO 已溢出的事件，不能把此实现表述为任意阻塞下都不丢键。
- `ViewTransition` 分离最后完整显示视图、请求目标和代次。准备中重复按 View 合并为相同请求；完成后才可反向，不重置加载或计时。
- 准备期间保留原画面，不加转圈或加载标识；完成后才发布偏好。明确资源失败或连续 5 秒无进展记录具体原因，使用底栏短暂“切换失败”反馈，不无限等待。
- 无歌词仍 Cover-only。Tab 只导航、Enter 仍重播、Esc 逐层返回，不新增完整 P4 控制。

### 列表、字体与媒体

- 同窗口仅更新旧、新选中行；缓存返回保留窗口和光标，选中行优先准备。标题与已就绪行可先画，不等六行和全部字体一起完成。
- 移除失败字体准备也要等待 20 ms 的旧限频。只准备可见最终文本，冷加载提示限定在底部状态区，页面代次防止旧媒体条带回写。
- 新增 FIDX v2 `.idx2`：512-byte 头、16-byte 定长记录，BMP / Latin 直接定位一个索引页；保留旧 `.idx` 缺省兼容。校验头、VLW 长度及头指纹，记录格式或配对错误，不伪装成缺字。
- 不增大 15 KiB 字模缓存或 200 项度量表；字模去重、按字体与记录顺序准备，批量整理淘汰空间。
- Cover 页继续准备当前及下一歌词，复用两份有界布局和当前/下一文本槽。按语言复用只读句柄，离页关闭闲置句柄，保留同曲索引及校验结果。
- 前奏灰色首组第一页，到时原位点亮；正常播放只显示当前组。没有改原 LRC 时间戳或人为补偿偏移。
- 新 `ImageBand` 使用既有 135×18 行缓冲，每次读取≤512 bytes，条带完整后一次提交；条带准备时占有缓冲，Header / Footer 在边界获得使用机会。
- CRC 校验与画面结束分离，同曲有效校验结果不因 View / 浮层 / 往返重复丢弃。新旧封面尺寸兼容，不重生成全部歌曲 ASCII。

### 存档与调度

- `PlayerRuntime::serviceAudio()` 与 `servicePersistence()` 分开，历史 Gate 保留兼容调用。主循环音频优先，后台 6 ms 软预算，不在每个小步骤之间机械等待音频缓冲。
- Queue 路径准备每次一个；目标检查、打开、写、Flush、关闭、回读打开/头/数据、清理和发布分别推进。
- 仅重写非当前槽；同长度原位写，长度变化才重建。Queue 验证发布后再关联 Session，失败保留旧有效配对。格式、CRC 和恢复暂停语义不变。
- 显示设置和日志的 Flush / Close 也分步，避免与完整歌词呈现、其他保存叠加；T 的成功提示等待真实保存完成。
- 单个 SD API 不可抢占，6 ms 不是硬实时保证。新增各存档阶段、音频源读取、UI 和资源准备测量；若单次调用仍超限，需要用下一轮设备日志继续定位，不增加豁免。

### 日志

记录捕获按键时间、动作接受、View 请求/就绪/首条带/完整呈现时间、冷热完成次数、重复请求合并、取消及失败原因。
冷热分类在请求发生时固定；没有完成次数的零延迟不算通过。首错保留，缺少覆盖仍为 INCOMPLETE。
新增字段随原周期检查点写入，不增加高频 SD 日志；日志按版本和启动编号区分。

## 6. 用户自由验收

只通过 Launcher 安装 `/firmware/ADV-Walkman-P3ABC-Gate.bin` 一次，没有顺序 Gate，也不会自动切歌、Seek、暂停或重启。

1. 播放和暂停分别按 Tab 往返；检查进度/暂停状态保留。Enter 仍从头选播。
2. Cover / Lyrics 各按一次实体 View；准备时再按几次，不能反向取消。正常等待不应出现加载标识。
3. 浏览同窗口、翻页、Esc 返回，检查首屏、选择反馈和残留；不要只停在播放器。
4. 自选 Sophie、Symbol 1、Black Birthday、Crucifix X，观察歌词与切换；暗黑天国确认无歌词回退。检查全宽曲库图及居中标题。
5. 自然操作至少累积 60 秒连续播放，包含真实资源、View、浏览、浮层和日志负载。不必逐首听完，也不必盯某个画面。
6. 息屏后首键只唤醒；T 等“已保存”，可手动重启确认恢复暂停，再把 SD 插回 PC。

后台按捕获/接受、可交互首屏、完整画面分别记录。验收仍要求：输入≤50 ms，选择≤100 ms，暖返回≤300 ms，暖 View≤300 ms，冷 View≤1500 ms，歌词呈现≤100 ms，正常预取到期更新≤200 ms，PCM≤70 ms，Audio Error / Backpressure 为零。

尚未覆盖的设置持久化、Launcher 返回、息屏组合键及主观显示/听感继续列为待验，不因这轮 PC 检查自动通过。新日志与人工确认齐全后才分别收口 P3A/B/C/D。
若单个 SD 操作仍超限，报告操作、歌曲、页面及差距；不改音频 Backend、缓冲或通过标准。本轮不 push，不操作 Flash、分区表或 eFuse。
